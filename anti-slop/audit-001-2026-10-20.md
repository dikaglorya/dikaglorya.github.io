### P0, fix dulu

1. Foto profil bukan foto Dika, tapi diberi label "Portrait of Dika".
   - Dipakai di hero, About, 404, `apple-touch-icon.png`, dan OG card.
   - Gambarnya orang dengan wajah pixel dan tanda tanya besar, plus overlay kode biru. First impression-nya "template hacker/crypto", bukan portfolio developer.
   - Alt text-nya klaim itu portrait Dika. Kalau memang bukan, itu misleading.
   - Fix: pakai foto asli (wajah atau workspace), atau hapus dan ganti dengan type-only/artefak nyata. Kalau tetap anonim, jangan sebut "Portrait of Dika".
   - Rules: R-23, R-38, C-5, R-20.

2. Aset brand di luar halaman masih identitas lama.
   - `public/og-default.png`: "DikaOfc", "Jasa Website & Bot", "di Kendal, Jawa Tengah", bahasa Indonesia.
   - `public/favicon.svg`: huruf G gold `#D9C9A3`.
   - `public/apple-touch-icon.png`: foto profil anonim.
   - Situs live: English, aksen cyan `#8ec9dc`, wordmark "obitoglory.".
   - Jadi ada tiga identitas: OG card lama, favicon gold, dan situs cyan.
   - Fix: regenerate OG dalam bahasa Inggris dengan wordmark dan aksen yang sama, lalu samakan favicon dan apple-touch-icon.
   - Rules: R-20, R-31.

3. Wordmark header rusak: "obitoglory .".
   - `.wordmark` pakai `display: inline-flex; gap: 10px`. Dot jadi flex item, jadi gap-nya masuk antara nama dan dot.
   - Muncul di header semua halaman dan menu mobile. Footer benar karena bukan flex.
   - Ukurannya: nama berakhir sekitar x=100, dot mulai x=110.
   - Fix: bungkus nama dalam span, atau hapus gap dan kasih margin hanya ke `.wordmark__sub`.
   - Rule: R-31.

4. Diagram DikaRoute tidak kebaca di mobile.
   - `RouteDiagram.astro` render dua SVG: desktop dan mobile.
   - CSS `.route-diagram--mobile { display: none }` dan tidak pernah di-override.
   - Di 390px, SVG desktop diskalakan dari 640 ke 320, scale 0.5. Label 13px jadi 6.5px, label 9px jadi 4.5px.
   - Fix: tampilkan SVG mobile di bawah 700px, atau sederhanakan diagram desktop.
   - Rules: R-03, R-35.

5. Tap target mobile banyak yang di bawah 44px.
   - Wordmark header: 95x17.
   - Footer nav dan social links: tinggi 22px.
   - Contact block Telegram/GitHub: tinggi 18px.
   - "All projects" di section head: 235x38.
   - "Read the case study": 156x26.
   - Yang sudah benar: tombol utama 44px+, menu 44px, filter 44px, input 46px.
   - Fix: min-height 44px dan padding vertikal untuk wordmark, footer links, dan contact block links. Link di dalam paragraf boleh dibiarkan.
   - Rule: R-03.

6. Form kontak bilang 3 field wajib, padahal 4.
   - Intro: "Name, email, and service are required."
   - `#message` juga `required`, tapi labelnya "What you need" tanpa tanda bintang.
   - Test: isi nama, email, service, submit. Form diblokir dan fokus pindah ke message.
   - Fix: tandai message wajib dan update copy, atau jadikan message opsional.
   - Rules: R-31, R-38.

## Resolution, 2026-10-20 (v2.0 rebuild applied)

All thirteen findings were resolved in the v2.0 rebuild. Per item:

1. **Portrait identity** — RESOLVED by removal. The site is now entirely type-led: no portrait, no hero image. The masked portrait is no longer used anywhere (`src/assets/` removed). Alt-text drift is therefore moot. The OG leading sentence ("jangan sebut Portrait of Dika" option) was realized by removing the image altogether.
2. **Brand assets split identity** — RESOLVED. `og-default.png` regenerated as a 1200×630 English type-led card via `scripts/generate-brand.mjs` (`npm run brand`, Chromium-rendered with the real Inter/Newsreader/JetBrains Mono woff2s). favicon and `apple-touch-icon.png` (180×180, via sharp) share the same cyan O-dot mark on the same `#08090b` background. One identity: site, OG, favicon, touch icon.
3. **Wordmark gap** — RESOLVED. The name is wrapped in `.wordmark__name`, so the flex `gap` applies between name and sub-label only, not inside the wordmark.
4. **DikaRoute diagram unreadable on mobile** — RESOLVED. A `max-width: 700px` media query shows the dedicated mobile SVG and hides the desktop one.
5. **Tap targets below 44px** — RESOLVED. `channel-list a`, `footer__nav a`, `footer__social a`, `.section-head__meta a` carry inline-flex with `min-height: 44px`; `.wordmark` has `padding-block: 14px`.
6. **Form copy vs required fields** — RESOLVED. Copy now reads "Name, email, service, and message are required"; the message label carries the required mark. Also hardened: the form is `novalidate` so the custom validation and status line always run, and the success status renders a real fallback `mailto:` draft link for browsers that block script-initiated handoffs.
7. **Default-AI typography** — RESOLVED with a written direction: Newsreader Variable for display (editorial-journal voice), Inter for body, JetBrains Mono for system metadata; reasons recorded in README and the design report. Weight/scale variation is used across headings and eyebrows.
8. **Hero template split** — RESOLVED. The hero is now a typographic statement (editorial standard eyebrow / serif statement / mono meta row); inner pages keep a shared but deliberately quieter page-hero rhythm per the declared RHYTHM dial.
9. **Split accent colors** — RESOLVED. One accent (`#8ec9dc`) across site, favicon, touch icon, and OG card; the gold `#D9C9A3` and the blue-photo identity are gone.
10. **Project pages without evidence** — PARTIALLY RESOLVED, by policy. Private work stays honest: live verified links only where they exist, the generic profile link was removed in favor of explicit "not published yet" notes, and no fabricated screenshots were added (per the no-fabrication rule).
11. **Generic copy + grammar** — RESOLVED. Hero and about copy rewritten around the actual service list; "are worked from zero" is now "built from scratch"; the "See all projects" CTA names its destination.
12. **Naming inconsistency** — RESOLVED. Footer nav matches header casing (lowercase mono), schema regions use "Central Java", service slugs are `website / bot / tools / repairs`, the pricing anchor is `#pricing`, and budget labels use "Rp1m/Rp3m".
13. **Section-head arrow wrapping** — RESOLVED. `.section-head__meta a` is inline-flex with a controlled gap; the arrow no longer breaks onto its own line.

Verification for the final state: `npm run check` 0 errors; `npm run build` 26 pages; `test:links` pass; `test:a11y` (axe, 7 pages × 3 viewports) pass; `test:visual` (4 viewports incl. 320px, menu/filters/copy-email) pass; R-35 click-through test of the contact form (empty submit → in-page status + focus, filled submit → prepared mailto draft in DOM, zero console errors) pass.
